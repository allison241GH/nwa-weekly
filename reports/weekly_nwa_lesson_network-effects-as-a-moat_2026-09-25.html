Network Effects as a Moat

September 25, 2026 · Topic: network-effects-as-a-moat

A network effect exists when each new user makes the product more valuable to every existing user — the telephone is worthless with one owner and indispensable with a hundred million. That is a fundamentally different kind of moat than a patent or a brand: it is a moat the customers themselves build and defend, because they'd have to coordinate a mass exodus to leave. In venture, this is the closest thing to a self-reinforcing flywheel — value compounds with scale instead of being competed away, which is exactly why the largest outcomes in the power law (marketplaces, social, payments, developer platforms) almost all have one underneath.

For an angel writing early checks, network effects matter because they're the rare moat that gets stronger precisely when a company is most vulnerable — at scale, when better-funded copycats show up. But you have to be ruthless about a distinction most pitch decks blur: a real network effect means the value to a user rises with the number of other users. That is not the same as "we'll have lots of users" (that's just traction), or "we get cheaper as we grow" (that's supply-side scale economies, which Amazon has but which don't lock anyone in the way a two-sided marketplace does). Ask: if a competitor launched tomorrow with an identical product but zero users, would my company's users still be better off because of who else is already here? If yes, you have a network effect. If the honest answer is "no, they'd switch for a 10% better UI," you have a feature.

The coaching insight business school underplays: network effects are a moat at scale but a curse at the seed stage — the "cold start problem." The same dynamic that makes a mature network unbeatable makes an empty one useless, so the first users get negative value. The best founders don't wait for the flywheel; they manufacture standalone value before the network exists (OpenTable gave restaurants a booking tool nobody else had; Uber flooded a single city with driver subsidies until riders never waited). So when you diligence a "network-effects business," your real question isn't "how strong is the moat at scale" — it's "what's the credible plan to survive the cold start," because most network-effect startups die empty, not out-competed. And in the AI era, be doubly skeptical: many "AI network effects" are really just data scale, which commoditizes as models improve — a genuine network effect needs users, not just data, reinforcing each other.

Key Terms

Network Effect — A property whereby each additional user increases the product's value to other users. Direct network effects come from same-side users (more people on WhatsApp = more people to message); indirect (two-sided) effects come from the other side of a marketplace (more drivers → shorter waits → more riders → more drivers).

Demand-Side Economies of Scale — The technical name for a network effect: value rises with the number of users on the demand side. Distinguish it from supply-side economies of scale (unit costs fall as you produce more), which lowers your cost but doesn't lock the customer in — only demand-side scale creates the "everyone's already here" switching barrier.

Real-World Example

Consider the two-sided marketplace canon Reid Hoffman lived at LinkedIn and preaches at Greylock: LinkedIn was useless to the first professional who joined, so it seeded value with a standalone address-book and identity page long before the network was dense — solving the cold start, then letting the network effect compound into a moat Microsoft paid $26B for. Contrast that with the graveyard of "Uber for X" and "social network for Y" startups that raised on the promise of a network effect but never cleared the cold start — same theoretical moat, opposite outcome, because the moat only exists once the network is full.

The lesson for an angel: the network effect is what makes the winner enormous, but it tells you almost nothing about which early-stage company will become that winner. Cold-start execution does.

Jamie's Action Prompt

Take one company in your current NWA pipeline (or one you're tracking) that pitches a "network effect." Write one sentence answering only this: what is the specific mechanism by which user N+1 makes the product more valuable to users 1 through N — and what gives the first 100 users a reason to show up before that mechanism kicks in? If you can't state both halves crisply, the moat is a hope, not a thesis — and that's your next diligence conversation with the founder.
